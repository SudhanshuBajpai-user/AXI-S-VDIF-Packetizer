PROJECT OVERVIEW — RED PITAYA VDIF PACKETIZER

1. PURPOSE
This project validates a VDIF packetization and UDP delivery pipeline on Red Pitaya / Zynq hardware. A counter provides deterministic test samples, the packetizer creates frames, a BRAM writer stores packet words, and the PS/software path transmits data over UDP to a PC for checking.

2. HIGH-LEVEL DATA FLOW
Counter test source -> VDIF packetizer -> AXI-stream output -> BRAM writer -> BRAM / Zynq PS -> UDP sender -> PC receiver and audit.

IMPORTANT: The currently inspected generated RTL connects the counter output to the packetizer data input. The ADC receiver exists in the design, but its output was not connected to the packetizer input in that RTL. Do not describe this as a verified live ADC-to-UDP pipeline until that connection is made and tested.

3. REPORTED SUCCESSFUL TEST
The reported multi-frame test received 10 UDP datagrams, each 1,056 bytes. All 10 passed the audit. Payload counter progression matched the expected 00, 01, 02, ... sequence, and VDIF frame numbers advanced from 702 to 711. The timestamp seconds field remained 217.
